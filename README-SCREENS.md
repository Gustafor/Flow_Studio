## Демо-видео (45–60 сек, 1080p)

Записать: **ShareX** (Win+Shift+R → «Record video») или Xbox Game Bar (Win+G). Готовый файл → `demo.mp4` в корне папки.

**Сценарий (комментировать голосом или титрами):**

1. **0–5 с** — заголовок: «Flow Studio — DAG-редактор агентов для Hermes».
2. **5–15 с** — сайдбар → Flow Studio → Create flow → Editor: быстро добавить 3 шага (Agent → Gateway XOR → Agent), в одном заполнить System prompt и Input template с `{{Имя шага}}`.
3. **15–25 с** — вкладка **Graph**: показать авто-раскладку, перетащить один блок, показать зум (Ctrl+колесо или кнопки).
4. **25–32 с** — **переключиться на JSON и обратно на Graph** — блоки на тех же местах (ключевой момент: «раскладка сохраняется»).
5. **32–40 с** — клик **▶ Запустить агента**, камера на чат: бриф появляется в поле ввода/отправляется, агент начинает выполнять (первый subagent-вызов).
6. **40–50 с** — вкладка JSON: показать файл потока (красиво, с `view`), кнопку Download.
7. **50–60 с** — финальный кадр графа + текст: `MIT · GitHub · hermes://plugin-desktop/repo=…`.

**Финальный монтаж:** не нужен — запись одной дорожкой. Формат: mp4 (h264), ≤ 30 МБ (для вставки в резюме/GitHub).
